
# ⚡ Smart Meter Energy Consumption Dashboard

An interactive Power BI dashboard analyzing household electricity consumption patterns, tariff distributions, and hourly usage trends using London smart meter data.

---

## 📊 Dashboard Preview

![Dashboard Screenshot](screenshot%203.png)

---

## 💡 Key Insights & Features

* **KPI Highlights:** Displays overall metrics including total kWh consumed ($546.94\text{K}$) and total readings/households ($5.021\text{K}$).
* **Hourly Consumption Profile:** Line chart tracking peak and off-peak electricity usage across half-hour intervals.
* **Socio-Economic Segmentation:** Bar chart comparing average energy consumption between `Affluent` and `Adversity` groups.
* **Tariff Type Distribution:** Donut chart breaking down energy usage share between Standard (`Std`) and Time-of-Use (`ToU`) tariffs.
* **Yearly Heatmap Matrix:** Detailed matrix view showing hourly consumption trends across multiple years ($2011 - 2014$).

---

## 🛠️ Tools & Technologies Used

* **Power BI Desktop:** Data modeling, DAX measures, and visual design.
* **Power Query:** Data cleaning, conditional column transformations, and grouping (`Acorn` classification).
* **Data Source:** Smart meter readings from London households (Kaggle).
